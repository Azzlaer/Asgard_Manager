# Estado del módulo remoto

La arquitectura prevista ya está integrada en ASGARD Host Manager v6.2:

- Control Center local.
- Remote Agent persistente.
- Bootstrap por OpenSSH.
- Transferencia SFTP con hashes.
- Red privada Tailscale recomendada.
- Biblioteca global portable.
- Despliegue múltiple, backups, logs y explorador de archivos.

Mejoras futuras posibles: actualizador automático del agente, permisos por operador, cola de despliegues, rollback de modpacks y panel web opcional.
